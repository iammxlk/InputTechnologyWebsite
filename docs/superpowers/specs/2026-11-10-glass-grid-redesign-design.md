# สเปก: รีดีไซน์แพลตฟอร์ม CAI เป็นสไตล์ Glassmorphism Grid Gradient

วันที่: 2026-11-10
Branch: `redesign/glass-grid`

## เป้าหมาย

เปลี่ยนหน้าตาแพลตฟอร์ม CAI วิชา 21901-2017 ทั้งระบบเป็นสไตล์มินิมอลกระจกฝ้าโทนม่วง
รองรับ Light/Dark โดยเนื้อหาและฟังก์ชันเดิมต้องไม่หาย ยกเว้นมินิเกมที่ผู้ใช้สั่งให้ถอดออก

## เงื่อนไขที่ห้ามพัง (ตรวจอัตโนมัติทุก Phase)

1. เนื้อหา: `CURRICULUM_DATA` 16 หน่วย 96 ขั้น 160 ข้อสอบ และ `APP_CONFIG` ต้องให้ลายนิ้วมือ
   (SHA-256 ของข้อความที่ตัดอักขระสัญลักษณ์ออกแล้ว) เท่ากับ baseline
   ข้อยกเว้นเดียวคือการแทนลูกศร Unicode ในเนื้อหาด้วยข้อความ/ไอคอน ซึ่งต้องไม่เปลี่ยนตัวอักษรอื่น
2. ฟังก์ชัน: สคริปต์ smoke test ต้องผ่านครบ
   สมัครสมาชิก, ล็อกอิน, ออกจากระบบ, แก้โปรไฟล์/รูป, เปิดอ่านครบ 16 หน่วยทุกขั้น,
   กติกาห้ามข้ามขั้น, แบบทดสอบท้ายหน่วย (ผ่าน/ไม่ผ่าน/เฉลย), หน้าความคืบหน้า,
   เกียรติบัตร (ล็อก/ปลดล็อก/ดาวน์โหลด), แล็บ EAN-13, สลับธีม, เสียง, โหมดลดการเคลื่อนไหว
3. ไม่มี console error และไม่มี 404

## ขอบเขต

ทำ
- เขียน CSS ใหม่ทั้งชุด คงชื่อ class/id ที่ JS ใช้
- แก้ markup เฉพาะที่จำเป็น: หน้าแรก (Hero + Glass Grid), หน้าอ่านบทเรียน, inline style ที่ฝังสี
- sprite ไอคอน SVG ชุดเดียว แทนอิโมจิ/อักขระสัญลักษณ์ใน UI ทั้งหมด
- ปุ่มบุ๊กมาร์กหน่วย (ฟีเจอร์ใหม่ชิ้นเดียว เก็บใน localStorage ไม่ซิงก์)
- ถอดมินิเกมและ Leaderboard ออกจากหน้าเว็บ
- ลบ `_legacy_v1/`
- เขียน `DESIGN.md` ใหม่จากงานที่เสร็จ

ไม่ทำ
- ไม่แตะ `backend/Code.gs` และชีต Google (รวม `MiniGame_Records`)
- ไม่เปลี่ยนตรรกะคะแนน เกณฑ์ผ่าน การล็อกขั้น รูปแบบข้อมูลที่ส่งเซิร์ฟเวอร์
- ไม่เปลี่ยนงานศิลป์ของภาพเกียรติบัตรที่ดาวน์โหลด
- ไม่เพิ่มปุ่ม "ทำเครื่องหมายว่าเรียนจบ" (สถานะจบมาจากการสอบผ่าน 8/10 ตามเดิม)
- เครื่องหมายคณิตศาสตร์ในสูตรของเนื้อหา (เช่น เครื่องหมายคูณ) คงไว้

## ดีไซน์

โทเคน: ตามบรีฟข้อ 2 ครบทุกตัว เพิ่ม
`--surface`, `--surface-2`, `--text-body`, `--text-muted` (ผ่าน AA),
`--success`, `--warning`, `--danger` พร้อมคู่พื้น/ตัวอักษร, `--line` เส้นขอบบนพื้นเรียบ
`--text-secondary` ของบรีฟไม่ผ่าน AA จึงใช้เฉพาะป้ายตกแต่งขนาดใหญ่

ฟอนต์: Inter Tight (ละติน/ตัวเลข), IBM Plex Sans Thai (ไทย), IBM Plex Mono (โค้ด/รหัส)
ข้อความไทย letter-spacing 0 และ line-height หัวข้อใหญ่ไม่ต่ำกว่า 1.2

ไอคอน: `<symbol>` ทั้งหมดใน `<svg>` ซ่อนต้น `<body>`, viewBox 24, stroke currentColor 1.75,
เรียกด้วย `<use href="#icon-...">` ทั้งใน HTML และเทมเพลต JS

สี: ม่วงโทนเดียวทุกหมวด แยกหมวดด้วยเลขและป้าย สีอื่นใช้กับสถานะเท่านั้น

พื้นผิว: กระจกฝ้าใช้กับ header, การ์ดนำทาง, ของตกแต่ง ส่วนเนื้อหาอ่านยาว แบบทดสอบ ฟอร์ม
อยู่บน `--surface` เรียบ

หน้าแรก: Hero (ป้ายหมวด 2 บรรทัด, หัวข้อ 2 บรรทัด, ข้อความข้าง, ประกาย, ปุ่มเริ่มเรียน, แถบสถิติ)
แล้วต่อด้วย Glass Grid ขั้นบันได seeded random ซ้อนการ์ดหน่วย

หน้าอ่าน: สารบัญ sticky ซ้าย (ลิ้นชักบนมือถือพร้อม focus trap), การ์ดเนื้อหา `--surface` มุม 20px,
แถบความคืบหน้าการเลื่อนอ่านติดขอบบน

ธีม: ค่าเริ่มต้นตาม `prefers-color-scheme` ถ้าเคยเลือกไว้ใช้ค่าที่บันทึก (`cdti_theme`)

มาสคอต: เอาสติกเกอร์ลอยขอบจอออก คงไว้ที่หน้าล็อกอิน ผลแบบทดสอบ เกียรติบัตร

แอนิเมชัน: ตามบรีฟข้อ 6 ปิดทั้งหมดเมื่อ `prefers-reduced-motion` หรือ `data-motion="reduced"`
