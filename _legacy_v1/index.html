COURSE OBJECTIVES • 21901-2017

จุดประสงค์รายวิชาและสมรรถนะการเรียนรู้

หลักสูตรประกาศนียบัตรวิชาชีพ (ปวช.)
OBJ 01

เข้าใจพื้นฐานข้อมูลและวงจรการประมวลผล (IPO & GIGO)

จำแนกความแตกต่างระหว่างข้อมูลดิบ (Raw Data) กับสารสนเทศ (Information) เข้าใจข้อมูลทั้ง 5 ประเภท และเปรียบเทียบการนำเข้าข้อมูลแบบ Manual กับ Automatic Input (AIDC)

OBJ 02

เลือกใช้อุปกรณ์นำเข้าข้อมูล บาร์โค้ด QR Code และ RFID ได้ถูกงาน

เข้าใจกลไกของคีย์บอร์ด เมาส์ เซนเซอร์กล้อง ไมโครโฟน หัวอ่านบาร์โค้ด 1D/2D รหัสภาพ QR Code 4 ตระกูล คลื่นความถี่ RFID (LF/HF/UHF) และระบบชีวมิติ (Biometrics)

OBJ 03

คำนวณรหัสตรวจสอบ ขนาดไบต์ และการบีบอัดข้อมูลอย่างเป็นขั้นตอน

คำนวณเลขตรวจสอบ Check Digit (EAN-13) ตั้งค่าสมดุลความปลอดภัยชีวมิติ (FAR/FRR/EER) คำนวณขนาดไบต์ UTF-8/TIS-620 และบีบอัดข้อมูลด้วยวิธี RLE ได้อย่างแม่นยำ

OBJ 04

ตรวจสอบความปลอดภัยไซเบอร์และเตรียมข้อมูลเข้าสู่ฐานข้อมูล

ป้องกันภัยคุกคามจาก QR Code ปลอม (Quishing) เข้าใจการเข้ารหัสผ่านด้วย SHA-256 + Salt และการทำความสะอาดข้อมูล (CSV/JSON/Power Query) ก่อนนำเข้าสู่ระบบ
