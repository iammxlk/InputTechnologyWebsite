# Neo-Brutalist UI, Motion & Interactive Visuals Skill (Antigravity Ready)

สกิลเฉพาะทางสำหรับระบบ AI Coding Agent (เช่น **Antigravity**) ในการออกแบบและเขียนโค้ด UI/UX สไตล์ **Neo-Brutalism / Playful Modern (สไตล์ Stwedy)** สำหรับเว็บการศึกษารายวิชา เทคโนโลยีการนำเข้าข้อมูลสู่ระบบคอมพิวเตอร์ (21901-2017)

## 1. Visual Design System & Typography (กฎเหล็กฟอนต์และดีไซน์)
- **Typography (ห้ามเปลี่ยนฟอนต์เด็ดขาด):**
  - **ภาษาอังกฤษ / ตัวเลข / หัวข้อหลัก (Display & Brand):** ใช้ฟอนต์ **`Stack Sans Notch`** (ดึงผ่าน Google Fonts: `https://fonts.googleapis.com/css2?family=Mitr:wght@300;400;500;600;700&family=Stack+Sans+Notch:wght@200..700&display=swap`) สำหรับหัวข้อภาษาอังกฤษ, ป้าย Badge, ตัวเลขคะแนน และ UI เด่นๆ เพื่อให้ได้เอกลักษณ์ทรงเรขาคณิตแบบมีรอยบาก (Notch) สไตล์โมเดิร์น
  - **ภาษาไทยทั้งหมด (Thai UI & Content):** ใช้ฟอนต์ **`Mitr`** (`font-family: 'Mitr', sans-serif;`) สำหรับหัวข้อภาษาไทย, เนื้อหาบทเรียน, ปุ่มกด, โจทย์ควิซ และหน้าเกียรติบัตรทั้งหมด (ใช้น้ำหนัก 300, 400, 500, 600, 700)
  - **กำหนด CSS Font Stack มาตรฐาน:** `font-family: 'Stack Sans Notch', 'Mitr', sans-serif;`
- **Crisp Black Borders:** ทุกคอมโพเนนต์ (การ์ด, ปุ่ม, กล่องข้อความ, Modal, กรอบภาพอุปกรณ์) ต้องมีเส้นขอบสีดำทึบ `border: 2px solid #000` หรือ `3px solid #000`
- **Hard Drop Shadows:** ห้ามใช้เงาฟุ้งเบลอ ให้ใช้เงาทึบสีดำคมชัด:
  - การ์ด/ปุ่มปกติ: `box-shadow: 4px 4px 0px #000`
  - การ์ดเด่น/Modal: `box-shadow: 7px 7px 0px #000`
- **Color Palette:**
  - พื้นหลังหลัก: ขาวนวล `#FAFAFA` และการ์ดสีขาว `#FFFFFF`
  - สีหลัก (Primary): เขียวมะนาวสด `#34D399` (`bg-emerald-400`)
  - สีรอง (Secondary): เหลืองสด `#FDE047` (`bg-amber-300`)
  - สีเน้น/แจ้งเตือน (Accent): ชมพูสด `#F472B6` หรือ ฟ้าสด `#38BDF8`

## 2. Motion & Micro-Interactions (ความว้าวและการตอบสนอง)
- **Tactile Buttons (ปุ่มกดสู้มือ):**
  - `hover`: ขยับลอยขึ้น `transform: translate(-2px, -2px)` และเงาขยายเป็น `6px 6px 0px #000`
  - `active`: ยุบตัวลงตามนิ้วกด `transform: translate(2px, 2px)` และเงาหดเหลือ `1px 1px 0px #000`
- **Card Hover & Bouncy Badges:** การ์ดบทเรียนขยับยกตัวเมื่อชี้เมาส์ ป้ายสถานะหรือป้ายคอมโบ (`🔥 คอมโบ x2!`) มีแอนิเมชันเด้งขยายตัว (`scale-110` / Spring transition)
- **Celebration Effect:** เมื่อปลดล็อกเกียรติบัตรหรือจบมินิเกมด้วยคะแนนผ่านเกณฑ์ ต้องมีเอฟเฟกต์พลุกระดาษ (Confetti) เฉลิมฉลอง

## 3. Interactive Hardware Lab (ภาพอุปกรณ์เสมือนจริงที่กดทดลองใช้ในเว็บได้)
ในหน่วยการเรียนรู้เกี่ยวกับอุปกรณ์นำเข้าข้อมูล **ห้ามมีแต่ตัวหนังสือเด็ดขาด** Antigravity ต้องเขียนโค้ดสร้างภาพประกอบอุปกรณ์แบบ Interactive (Custom SVG + CSS/JS Animation ในกรอบ Neo-Brutalism) ที่นักเรียนคลิกหรือกดทดลองใช้งานบนหน้าเว็บได้ทันที:
- **แป้นพิมพ์ & เมาส์ (หน่วยที่ 3):** มีภาพปุ่มคีย์บอร์ดจำลอง เมื่อกดแล้วแสดงไฟวิ่งตามเส้นทางสัญญาณ `Key Matrix` -> แปลงเป็นรหัส `Scan Code` (เช่น `0x1E`) ขึ้นบนจอจำลองทันที
- **กล้องดิจิทัล & ไมโครโฟน (หน่วยที่ 4):** มีปุ่มกดชัตเตอร์จำลองการรับแสงผ่านเซนเซอร์ CMOS (แสดงตารางพิกเซล RGB) และปุ่มพูดใส่ไมค์จำลองคลื่นเสียง Analog แปลงผ่าน ADC เป็นเลขฐานสอง `0101`
- **เครื่องยิงบาร์โค้ด CCD vs 2D Imager & ไร้สาย (หน่วยที่ 5-6):** มีภาพปืนสแกนเนอร์ให้นักเรียนกดปุ่ม "ยิงลำแสงเลเซอร์สีแดง" ใส่ภาพบาร์โค้ด EAN-13 พร้อมเสียงเอฟเฟกต์ *ติ๊ด!* (Web Audio API) และแสดงผลลัพธ์การถอดรหัสตัวเลข
- **QR Code Damage Tester (หน่วยที่ 7-8):** มีภาพ QR Code ที่นักเรียนลองคลิก "ทำรอยเปื้อน/ฉีกขาด" แล้วกดสแกน เพื่อทดลองดูการทำงานของระบบกู้ข้อมูล Reed-Solomon (ระดับ L 7%, M 15%, Q 25%, H 30%)
- **เครื่องอ่าน RFID & แท็ก (หน่วยที่ 11):** มีภาพบัตร/แท็ก RFID ให้นักเรียนคลิกหรือลากไปแตะที่เครื่องอ่าน (Reader) เพื่อจำลองการปล่อยคลื่นวิทยุเหนี่ยวนำและอ่านค่า UID ขึ้นหน้าจอ
- **เครื่องสแกนลายนิ้วมือ/ใบหน้า (หน่วยที่ 12):** มีปุ่มวางนิ้วสแกน พร้อมเส้นเลเซอร์วิ่งสแกนจุดตัดลายนิ้วมือ (Minutiae) และแถบเลื่อน (Slider) ให้ลองปรับค่า Threshold ดูผลกระทบต่อค่า FAR/FRR แบบเรียลไทม์

## 4. Human-Friendly Thai Copywriting (กฎเหล็กการใช้ภาษาไทย)
- **ห้ามใช้ภาษา AI หรือคำแปลกปลอมที่ดูเว่อร์วัง:** ห้ามใช้คำว่า *"ยกระดับศักยภาพ", "เปิดประสบการณ์แห่งโลกอนาคต", "นวัตกรรมอัจฉริยะไร้ขีดจำกัด", "ปลดล็อกพันธนาการความรู้"*
- **ใช้ภาษาพูดที่เป็นกันเอง เหมือนครูวัยรุ่นคุยกับเด็ก ปวช.:** สั้น กระชับ ชัดเจน เข้าใจง่าย เช่น:
  - *"กดลองยิงบาร์โค้ดดูเลย!"*
  - *"อ่านจบแล้วกดติ๊กตรงนี้นะ คะแนนจะได้ขึ้น"*
  - *"มาลองทำควิซเช็กความเข้าใจกันหน่อย 3 ข้อสั้นๆ"*
  - *"เก่งมาก! คะแนนถึงเกณฑ์แล้ว กดโหลดใบเกียรติบัตรไปอวดเพื่อนได้เลย"*
